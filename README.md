# Home Planner

类似 Planner 5D 的室内设计工具，支持2D编辑和3D预览。

## 功能

- 🏗️ 2D编辑：画墙体、放置/拖拽/旋转家具
- 🎨 3D预览：实时三维渲染，轨道控制
- 🪑 家具库：20+预置家具模型，分类管理
- 📐 尺寸标注：网格对齐，精确控制

## 技术栈

- React + TypeScript
- Konva.js (2D Canvas编辑)
- Three.js + React Three Fiber (3D渲染)
- Zustand (状态管理)
- Vite (构建工具)

## 开发

```bash
npm install
npm run dev
```
